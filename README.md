Seaborn and Python.

- Bar Plots
- Count Plots

- Scatter Plots
- Line Plots
- Box Plots

- Customization of plots
- Titles, labels and legends
- Plot styling and formatting

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
